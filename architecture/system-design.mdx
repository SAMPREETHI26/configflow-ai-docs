# System Design

The system is divided into presentation, API, application, and integration layers.

## Presentation Layer

The React frontend provides document upload, analysis results, configuration previews, and validation feedback.

## API Layer

FastAPI exposes backend functionality through REST endpoints.

## Application Layer

The application layer contains the Analyzer, AI Agents, Decision Engine, Generators, and Validators.

## Integration Layer

The integration layer communicates with systems such as SNDB, Git repositories, and engineering file storage.
